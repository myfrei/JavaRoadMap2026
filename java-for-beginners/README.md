# 🐣 Java для новичков — быстрый практический трек

> 12 коротких уроков с кодом: от первой программы до тестов. Если Java — твой первый серьёзный язык,
> пройди этот трек, а потом возвращайся в [основную программу](../README.md) с
> [Модуля 0. Фундамент](../course/00-fundamentals.md).

> ⚙️ **Статус: каркас.** Уроки наполняются кодом и заданиями по шаблону ниже. Каждый урок — это
> рабочий пример + ключевые концепции + задание для самостоятельного решения.

**Где писать код:** проще всего в [JShell](https://docs.oracle.com/en/java/javase/25/jshell/) (`jshell` в терминале)
или в любом модульном подпроекте, например `modules/m00-fundamentals/`.
