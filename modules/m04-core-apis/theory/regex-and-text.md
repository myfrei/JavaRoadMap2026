# Регулярные выражения и работа с текстом

> Модуль 4 — Core APIs · [к модулю](../../../course/04-core-apis.md)

## Зачем это нужно

Регулярные выражения — компактный язык описания текстовых шаблонов: «найди все email», «проверь
формат телефона», «вытащи числа». Без них пришлось бы писать громоздкие циклы. Но у regex есть и
ловушки (производительность, читаемость), о которых полезно знать сразу.

**Где применяется в проектах:** валидация ввода (email, телефон, промокод); парсинг логов; извлечение
данных из текста; нормализация (slug для URL); линтеры и анализаторы.

## Pattern и Matcher

`Pattern` компилируется один раз и переиспользуется (это дорогая операция — не компилируй в цикле):

```java
import java.util.regex.*;

// \b — граница слова; класс символов для «логина» и домена
private static final Pattern EMAIL =
        Pattern.compile("[\\w.+-]+@[\\w-]+\\.[\\w.-]+");

List<String> extractEmails(String text) {
    List<String> out = new ArrayList<>();
    Matcher m = EMAIL.matcher(text);
    while (m.find()) {                 // ищем все вхождения
        out.add(m.group());            // group() — совпавшая подстрока
    }
    return out;
}
// "write a@b.com and c.d@e.org" -> [a@b.com, c.d@e.org]
```

Ключевое: `Pattern.compile` — в статическое поле; `matcher` + `find` — для поиска всех совпадений.

## Группы захвата

Скобки `( … )` выделяют части совпадения:

```java
Pattern KV = Pattern.compile("(\\w+)=(\\w+)");   // group(1)=ключ, group(2)=значение
Matcher m = KV.matcher("port=8080");
if (m.matches()) {
    System.out.println(m.group(1) + " -> " + m.group(2)); // port -> 8080
}
```

## replaceAll и нормализация

```java
String slug = "Hello, World! 2026"
        .toLowerCase()
        .replaceAll("[^a-z0-9]+", "-")  // всё не-буквенно-цифровое -> дефис
        .replaceAll("^-|-$", "");        // убрать дефисы по краям
// "hello-world-2026"
```

## Текстовые блоки (text blocks)

Для многострочного текста (JSON, SQL, HTML) — `"""`:

```java
String json = """
        {
          "name": "Ann",
          "age": 30
        }
        """;
```

Не нужно экранировать кавычки и склеивать строки через `\n`.

## Ловушки

- **Не компилируй `Pattern` в цикле** — выноси в статическое поле.
- Бойся **катастрофического бэктрекинга** (вложенные кванторы вроде `(a+)+`) — на «злом» вводе
  это вешает CPU (ReDoS). Для критичного ввода держи шаблоны простыми.

## Итог

**Что изучено:**
- `Pattern`/`Matcher`, `find`/`matches`/`group`, группы захвата.
- `replaceAll` для нормализации; текстовые блоки для многострочных литералов.
- Производительность: компиляция в поле, опасность ReDoS.

**Как применять на практике:**
- Валидировать и извлекать данные шаблонами вместо ручных циклов.
- Компилировать `Pattern` один раз; держать выражения читаемыми и простыми.
- Для сложного разбора (целые языки/форматы) брать настоящий парсер — см. модуль 19.
