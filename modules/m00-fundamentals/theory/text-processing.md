# Обработка текста: String, StringBuilder и циклы

> Модуль 0 — Фундамент · [к модулю](../../../course/00-fundamentals.md)

## Зачем это нужно

Текст — самый частый тип данных в работе: разбор аргументов командной строки, чтение конфигов и логов,
парсинг CSV/JSON, нормализация пользовательского ввода. Умение уверенно резать, склеивать и считать
строки экономит часы. А ещё это отличный полигон, чтобы прочувствовать неизменяемость (immutability)
и стоимость операций.

**Где применяется в проектах:** CLI-утилиты и парсеры; обработка логов; валидация и нормализация
ввода (email, слаги для URL); подсчёт статистики по тексту.

## String неизменяем (immutable)

Объект `String` нельзя изменить после создания — любые «изменения» создают **новую** строку.

```java
String s = "java";
s.toUpperCase();          // создаёт "JAVA", но РЕЗУЛЬТАТ НЕ СОХРАНЁН
System.out.println(s);    // java  (исходная строка не изменилась!)

String upper = s.toUpperCase();  // правильно: берём результат
System.out.println(upper);       // JAVA
```

Это типичный «красный флаг» новичка: вызвать `s.trim()`/`s.replace(...)` и забыть присвоить результат.

## Разбиение и склейка

```java
String line = "  a  b   c ";
String[] words = line.trim().split("\\s+");  // ["a", "b", "c"]
System.out.println(words.length);            // 3
```

- `trim()` убирает пробелы по краям, `split("\\s+")` режет по одному-и-более пробельным символам.
- Для сборки строки в цикле используй `StringBuilder` — он изменяемый и не плодит мусор:

```java
StringBuilder sb = new StringBuilder();
for (String w : words) {
    if (!sb.isEmpty()) sb.append(",");
    sb.append(w.toUpperCase());
}
String joined = sb.toString();   // "A,B,C"
```

Если в цикле склеивать через `result += w`, на каждой итерации создаётся новая строка — на больших
объёмах это заметно медленнее.

## Подсчёт частот через Map

```java
Map<String, Integer> freq = new HashMap<>();
for (String w : "go go java".split(" ")) {
    freq.merge(w, 1, Integer::sum);   // если нет ключа -> 1, иначе старое+1
}
// {go=2, java=1}
```

`merge` — лаконичный способ «увеличить счётчик»: не нужно вручную проверять наличие ключа.

## Итог

**Что изучено:**
- `String` неизменяем — результат методов нужно сохранять.
- `split`/`trim` для разбора, `StringBuilder` для эффективной склейки.
- `Map.merge` для подсчёта частот без ручных проверок.

**Как применять на практике:**
- Разбирать аргументы CLI, строки логов и конфигов.
- Нормализовать ввод (регистр, пробелы) перед валидацией и сохранением.
- В горячих участках не склеивать строки через `+` в цикле — брать `StringBuilder` (подробнее в модуле 11).
