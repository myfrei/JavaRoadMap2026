## 🎯 Проект модуля

**«Индексы и план запроса».**

1. Создай схему и наполни её данными (десятки тысяч строк) — например, заказы и клиенты.
2. Возьми набор «медленных» запросов и **подбери индексы** (составные, частичные, покрывающие) под них.
3. Докажи ускорение через **`EXPLAIN ANALYZE`** (план и время до/после), убери анти-паттерны (не-sargable предикаты).

- **Критерии приёмки:** для каждого запроса виден переход seq scan → index scan; время выполнения заметно падает; запросы из Java строятся через `PreparedStatement` (без конкатенации значений).
- **Код-скелет:** `modules/m22-postgres/` — `./gradlew :modules:m22-postgres:run`. Домашка: `:homeworkTest`.
