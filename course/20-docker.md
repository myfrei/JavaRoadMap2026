## 🎯 Проект модуля

**«Контейнеризация и масштабирование».**

1. Напиши **multi-stage** `Dockerfile`: стадия сборки (Gradle) → лёгкий runtime-образ с JRE, non-root user, `HEALTHCHECK`.
2. Подними окружение через **docker compose**: приложение + Postgres (с healthcheck и зависимостью `depends_on`).
3. Запусти приложение в **3 инстансах** и поставь перед ними **nginx-балансировщик** — один внешний порт, round-robin по инстансам.

- **Критерии приёмки:** образ собирается и весит разумно; `docker compose up --scale app=3` поднимает 3 копии; запросы распределяются между ними; падение одного инстанса не роняет сервис.
- **Готовый шаблон для старта:** [`modules/m20-docker/docker/`](../modules/m20-docker/docker/) (Dockerfile, docker-compose.yml, nginx.conf).
- **Код-скелет:** `modules/m20-docker/` — `./gradlew :modules:m20-docker:run`. Домашка: `:homeworkTest`.
